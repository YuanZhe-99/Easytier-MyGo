# 版本历史

项目于 2026-10-16 从 0.1.0 重新开始。此前继承的历史（直到 0.10.80）保存在 git tag `archive/v0.10.80` 下，不再延续。

## 0.2.3（2026-10-28）

- macOS：登录时打开现在会在托盘中启动。登录项启动时没有命令行参数，而界面在 macOS 能告知之前就询问是否为登录时打开，所以窗口总会打开。
- 应用更新可以自动安装：关于与更新 › 自动安装更新——关闭（默认）、空闲时（15 分钟未使用键盘或鼠标），或每天在所选的那一小时内。窗口关闭到托盘时安装的更新，重启后仍在托盘中。
- MyGo v0.7.1（由 v0.6.4 更新）/ EasyTier v2.6.4（2026-10-28 已检查，无变化）；打包用 UPX v5.3.0。

## 0.2.2（2026-10-25）

- 首次运行引导：电脑改为与 Kyokai 引导相同的画法——固定从左前上方看、不带透视、画得更大，系统标志端正地平放在顶面（Apple 标志略大），阴影更柔和。Windows Dev Kit 与 Mac mini 不再画接口；Linux 迷你主机保留凹槽，改画在可见的两个面上。电脑下方的文字和“虚拟网卡”标签相应下移。
- MyGo v0.6.4 / EasyTier v2.6.4（2026-10-25 已检查，无变化）。

## 0.2.1（2026-10-25）

- 首次运行：一段六步的引导取代了欢迎页——虚拟网卡、三种运行方式并排对比、开机与登录、保持在线，最后做出选择。每一步都有动画插图：本机以透视画成 Windows Dev Kit、Mac mini 或迷你主机，顶面印着所运行系统的标志。“跳过”以“免授权”方式开始；在“设置 › 运行方式 › 重看引导”中可以再看一遍。引导中可以设置“登录时打开”和界面语言。
- MyGo v0.6.4（由 v0.6.3 更新；Go 1.27.3）/ EasyTier v2.6.4（2026-10-25 已检查，无变化）。

## 0.2.0（2026-10-24）

- 参照 Kyokai 的新界面：侧边栏画在窗口材质上（Windows 11 用 Mica，macOS 用侧边栏材质），内容是一个浮起的小窗，它的标题栏就是窗口的标题栏。0.1.7 的标题栏条已移除；Windows 的窗口按钮画在标题栏里，macOS 的红绿灯按钮位于侧边栏上方，Linux 保留桌面自己的按钮。
- 侧边栏：网络带图标块和状态点，底部有活动记录、浅色/深色切换、设置和运行方式；可收成图标栏。
- 网络小窗：标题栏中有编辑和连接/断开；未连接的网络显示其配置（绝不包含密钥）；没有当前数据时只显示“没有当前数据”。后台服务的问题以卡片显示在标题栏下方。
- 编辑与添加网络：每个字段一行并带一句说明，标题栏中有“表单 | TOML”和“保存 / 保存并应用”，“删除网络”在最后。日志改为按天分组的活动记录。
- 设置改为盖住窗口的面板，带搜索，并重新分组：偏好 › 常规；本机 › 运行方式、EasyTier 内核；EasyTier MyGo › 关于与更新（“高级”并入其中的“诊断”）。
- 首次运行：运行方式是可选择的图块，只有一个“继续”按钮。
- MyGo v0.6.3（由 v0.6.2 更新）/ EasyTier v2.6.4（2026-10-24 已检查，未变化）。

## 0.1.7（2026-10-22）

- 窗口标题栏成为界面的一部分：顶部一条带应用标签的标题栏条代替系统标题栏，系统的窗口按钮位于其中（macOS 上是红绿灯按钮；Windows 上是带贴靠布局的标题按钮）。拖动标题栏条可移动窗口，双击可最大化，全屏时隐藏。
- 托盘：图标颜色随深色或浅色的菜单栏、任务栏变化。
- Linux：`.deb` 与 `install.sh` 不再需要 WebKitGTK（MyGo 的 `linux.webview`）。
- MyGo v0.6.2（由 v0.5.5 更新）/ EasyTier v2.6.4（已检查，未变化）。

## 0.1.6（2026-10-17）

- macOS：重新安装特权助手（“更新特权助手”横幅）后，助手可能没有运行：`launchctl bootout` 在旧任务移除之前就返回，随后的 `bootstrap` 失败。现在安装会等待旧任务结束并重试；已安装但未运行的助手会显示带“启动特权助手”的横幅。
- macOS：助手按代码签名自更新（新的可执行文件必须满足已安装副本的指定要求），因此此后的更新无需管理员批准。更新 0.1.5 及更早的助手还需批准一次。
- 网络页：没有来自后台服务的当前数据时，状态显示为“未知”，并隐藏流量、信息块和节点，而不是继续显示最后上报的“已连接”。
- MyGo v0.5.5 / EasyTier v2.6.4（已检查，未变化）。

## 0.1.5（2026-10-17）

- macOS：应用改用维护者的 Apple Development 证书（Team ID `982C6JDNCS`）签名，不再是 ad hoc 签名，因此 macOS 会在更新后保留隐私授权。从更早版本首次更新时会再请求一次。应用仍未经过公证：下载的副本需要移除一次隔离属性（[platform-notes.md](platform-notes.md)）。
- macOS：更新特权助手需要管理员批准，因为代码签名改变了其构建包清单所覆盖的文件。
- MyGo v0.5.5 / EasyTier v2.6.4（已检查，未变化）。

## 0.1.4（2026-10-16）

- 节点列表：机器风格的主机名显示为友好名称（`macbook-pro` → MacBook Pro，`Intel-NUC8i5BEH` → Intel NUC8i5BEH）；行的提示文字是原始主机名。
- 节点列表：主机名指向已知厂商、产品线、操作系统或服务商（Apple、Intel、Linksys、Windows 等）时，头像显示该厂商的标志；内置 63 个标志，来源见 `internal/gui/assets/logos/SOURCES.md`。
- 节点列表：右键点击节点可复制其 IP 地址、MagicDNS 名称（开启 `accept_dns` 时）或主机名；鼠标悬停时地址旁会出现复制按钮。
- 安全：特权助手的签名自更新先校验用户可写应用文件夹中的包，再重新读取其中每个文件来复制，因此以同一用户身份运行的程序可以在两次读取之间换入自己的二进制，使其被安装并以 root/SYSTEM 运行。现在助手只读取每个文件一次，并安装它所校验的那些字节（Windows、macOS、Linux）。
- MyGo v0.5.5 / EasyTier v2.6.4（已检查，未变化）。

## 0.1.3（2026-10-16）

- macOS：关闭窗口到托盘时也会隐藏程序坞图标；可在“设置 → 通用”中关闭。最小化时保留程序坞图标。
- 网络表单显示实例 ID：为空或缺失时换成新的 UUID，并有按钮重新生成。新建网络时也会生成一个。
- MyGo v0.5.5 / EasyTier v2.6.4（已检查，未变化）。

## 0.1.2（2026-10-16）

- 应用可从 GitHub 自行更新：每日检查（可关闭），以及“设置 → 关于”中的“检查更新”；更新经过签名（`MYGO_UPDATER_PRIVATE_KEY`），按需就地安装。软件包管理器安装的版本仍由它更新。
- Windows：特权助手误以为自己没有特权，拒绝所有带虚拟网卡的网络（“需要特权助手”）；现在改为检查进程令牌。向助手添加自定义内核也有同样的问题。
- 窗口底部的错误提示看不见（文字颜色未设置）；现在是红底白字。
- 不是 UUID 的 `instance_id` 会先被指出，而不是由内核不说明原因地拒绝。
- 更换了构建包签名密钥（`internal/bundlesig/release.pub`）：0.1.0 与 0.1.1 的助手只认旧密钥，因此把它们更新到 0.1.2 时需要一次管理员授权。
- MyGo v0.5.5 / EasyTier v2.6.4（已检查，未变化）。

## 0.1.1（2026-10-16）

- Windows：应用安装在含空格的路径下（默认的 `…\Programs\EasyTier MyGo`）时，从 GUI 安装特权助手会失败：管理员命令把构建包路径拆开了。现在参数按 Windows 命令行规则加引号。
- 欢迎页会显示运行方式选择失败的原因，而不是没有任何反应。
- MyGo v0.5.5 / EasyTier v2.6.4（已检查，未变化）。

## 0.1.0 — 重构后的首个版本（2026-10-16）

- 重置基线：删除继承的测试、测量脚本、验收文档和 ACL 编辑引擎；重写文档。
- 标识改为 `com.yuanzhe.easytiermygo`，模块改为 `github.com/YuanZhe-99/Easytier-MyGo`。
- MyGo v0.5.5 / EasyTier v2.6.4（2026-10-16 检查）。
- 获取 EasyTier 发布二进制时解除 UPX 压缩（每次 CLI 调用的 CPU 从约 250 ms 降到 3 ms）。
- 新运行时：网络存储、带应用回滚的每网络监管器、带会话的本地 API v2、运行方式（免授权/随界面/后台）以及 Linux 特权助手。
- 主动启动后的健康宽限期从 45 s 降到 15 s。
- 新 GUI：带实时流量图的仪表盘、含连接详情的节点列表、表单与 TOML 编辑、运行方式、内核管理、托盘、四种语言、浅色与深色主题。
- 安装包：Linux tar.gz 与 `.deb`、Windows 安装程序与便携 zip（x64、ARM64）、macOS 磁盘映像；签名的构建包让特权助手无需弹窗即可自更新。
- macOS 与 Windows 后端：已实现，CI 冒烟测试使用 `no_tun` 网络；已在真机验证（Apple M1 上的 macOS 27，包括 TUN 下的助手；Windows 11 ARM64 上的用户态 daemon 与助手，`no_tun`）。
- 尚未包含：结构化 ACL 编辑器、TCP/DNS 探测、持久化流量历史、监视外部内核。
- 内核管理：选择内置内核、下载官方版本（按需包含预发布）或添加自定义构建；内置 upx 5.2.1；适配器可读取 v2.6 与 v2.7 的输出。
