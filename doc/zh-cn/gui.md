# GUI

界面是桌面 VPN 客户端，而不是工程控制台（`internal/gui`）。本文档规定它遵循的规则；`internal/gui/gui_test.go` 会渲染所有页面并可输出截图（`SCREENSHOT_DIR`）。

## 窗口

- 窗口不使用系统标题栏（`TitleBarOptions`）：侧边栏画在窗口材质上——Windows 11 用 Mica，macOS 用侧边栏材质，其他平台用比小窗略深或略浅的底色（`windowBase`）——旁边是一个小窗：圆角 14 点、带边框和淡阴影的圆角框，离窗口边缘和侧边栏各 8 点（`App.pane`）。小窗 44 点高的标题栏就是窗口的标题栏（`paneHeader`）：页面的图标、标题和旁边的一行说明，然后是状态胶囊或一个选择，页面的操作，Windows 上还有窗口按钮。标题和空白处可拖动窗口，双击可最大化。
- **窗口按钮：** 在 Windows 上，系统按钮会落在窗口角上、一半在小窗外，所以窗口隐藏它们（`HideWindowButtons`），由标题栏在一条分隔线后绘制最小化、最大化或还原、关闭（`windowButtons`），最大化带 Windows 11 的贴靠布局；设置面板或对话框盖住窗口时，它们留在原位，以浅色画在暗层上。在 macOS 上，红绿灯按钮离窗口边缘 9 点，与标题栏同一中心线，位于侧边栏顶部一行之上，那一行从它们之后开始。在 Linux 上，桌面自己的按钮居中于与标题栏及其边距等高的标题栏中，标题栏为它们留出位置（`titleRoom`）。全屏时不留位置。
- **提示：** 无论显示哪一页都需要用户处理的事——特权助手比应用旧（更新特权助手）、特权助手未安装或未运行（运行方式设置、启动特权助手）、未连接到后台服务、数据不再更新——以警告色卡片显示在标题栏下方（`noticesView`）。提示消息显示在小窗底部。

## 侧边栏

- 顶部是“隐藏侧边栏”和“+”（添加网络），macOS 上位于红绿灯按钮之后；然后是“网络”及数量，每个网络一行（`sidebarNetwork`）：图标块及角上的状态点（状态未知时为灰色）、名称、已连接时的虚拟地址，否则用文字写出状态。正在显示的网络突出显示。
- 底部：活动记录、外观——跟随系统、浅色、深色轮换（带月亮的太阳、太阳、月亮）——、设置，以及运行方式：一个点和它的名称，或说明后台服务为何不可用（特权助手未安装、特权助手未运行、后台服务未运行、正在连接…），点击打开“设置 › 运行方式”（`runChip`）。
- 隐藏时侧边栏变成图标栏（`gui.json` 中的 `sidebar_rail`）：显示侧边栏、“+”、每个网络一个图标块（名称和状态在提示中），然后是底部的按钮和运行方式的点。macOS 上图标栏宽 72 点，让红绿灯按钮与图标共用一条中心线。

## 网络小窗

- **标题栏：** 网络名、网络名称、内核版本，不创建虚拟网卡时显示“不创建虚拟网卡”，状态胶囊；“编辑配置”（铅笔）和“连接”（主按钮）或“断开”。
- **已连接：** 未完全连接时说明原因（自动重启放弃后提供“重试”）；保存但未应用的更改以强调色提示条显示，带“立即应用”；流量卡（下载、上传、流量图及时间范围）；虚拟 IPv4、NAT 类型、在线节点数和已连接时长的信息块；然后是“节点 | 活动记录”，并提示右键点击节点行可复制地址，以及节点列表。
- **未连接**（`stoppedView`）：说明未连接、上述提示条，以及以行显示的配置（`summaryOf`，每个保存版本读取一次，绝不包含密钥）：网络名称、对等节点、地址、虚拟网卡和监听地址，带“编辑配置”；摘要无法读取的文档会如实说明。
- **没有来自 daemon 的当前数据**（没有会话，或几秒内没有更新）时，胶囊显示“未知”，“编辑”和“断开”不可用，小窗只显示“没有当前数据”，因此最后上报的状态绝不会看起来像当前状态（`shownStatus`）。
- **没有网络：** 小窗显示“还没有网络”，带“添加网络”和“导入文件…”。

## 编辑

- “编辑配置”在网络的小窗中打开；标题栏有“表单 | TOML”、“取消”、“保存”和“保存并应用”（保存与应用仍然分开）。
- 表单与设置页使用同样的行（`formView`）：网络（名称、网络名称、带“显示”的密钥、设备名称、带“重新生成”的实例 ID）、地址（自动获取、虚拟 IPv4）、连接（对等节点和监听地址是各自行下方的文本框、虚拟网卡）、路由（共享的子网、出口节点）、高级（默认折叠：各开关、设备名称、MTU），最后是“删除网络”。TOML 使用 MyGo 的编辑器，带行号；切换时带上未保存的修改。
- **添加网络**（`createDialogView`）是盖住变暗窗口的对话框：名称、网络名称、密钥、第一个对等节点和虚拟网卡以行显示，然后是“导入文件…”、“取消”和“创建”。
- **活动记录**（`logsView`，侧边栏的时钟）：所有网络最新的 100 条事件，按天分组（今天、昨天，否则为日期），每条带时间、状态点、句子及细节和所属网络；标题栏中有“导出诊断信息…”。

## 设置

- 设置从侧边栏的齿轮、底部的运行方式和托盘打开，绝不放在小窗里（`settingsSheet`）：盖住整个窗口（包括侧边栏）的面板，离左右 64 点、上 48 点、下 32 点，下面的窗口变暗。标题写“设置”，带 ×；按 Esc、点击外面或 × 关闭。
- 左边是搜索框和分组（`settingsGroups`）：偏好 › 常规；本机 › 运行方式、EasyTier 内核；EasyTier MyGo › 关于与更新。搜索框中有文字时，标题或说明包含每个词（不区分大小写）的设置会取代分组，标题匹配的排在前面，各自注明所在页（`settingsHits`、`searchSettings`；每个结果都显示在它的页面上，`TestSettingsHitsShow`）；选择一项会打开它所在的页、滚动到它并高亮两秒。
- 每页是一个标题和一句话，最宽 720 点，然后是若干分组：灰色标题，右侧可有说明或按钮，下面是圆角的行列表（`rows`）。每行以图标块开头，然后是标题和一句简短说明，最后是控件。
- **常规：** 语言与外观（语言、外观）；启动与关闭（登录时打开、登录时打开则在托盘中启动、关闭按钮，macOS 上还有隐藏程序坞图标）；通知（连接变化）。
- **运行方式：** 三种运行方式各一行，正在使用的标为“当前”，其余带“切换”，切换时显示加载指示（[run-modes.md](run-modes.md)），然后是“三种方式有什么区别？”及“重看引导”（[首次运行](#首次运行)）；特权助手：已安装时显示版本（比应用旧时有“更新特权助手”，以及“移除特权助手”），或未安装。
- **EasyTier 内核：** 每日检查发现更新的稳定版时显示提示条；已安装的内核（已测试或未测试、使用中、使用、移除）；每日检查；官方发布版本，带“显示预发布版本”和“检查发布版本”，每个版本带“下载（大小）”或“已安装”。
- **关于与更新：** 版本及“源代码”、许可证及 EasyTier 源代码、设计致谢及 EasyTier-iOS；应用更新——新版本带“安装并重启”、下载进度，或上次检查时间及“检查更新”——和每日检查，开启时还有自动安装（关闭、空闲时，或每天某一小时）；诊断：诊断文件（“导出诊断信息…”）和日志文件夹。
- **应用更新：** 每日检查和“检查更新”读取最新 GitHub 版本中的签名更新；“安装并重启”会原地安装并重新启动。免授权方式下，用户守护进程在安装期间停止（Windows 无法替换正在运行的程序），之后以新版本重新启动；随后助手会从签名包中更新自身（在 macOS 上按代码签名，[packaging.md](packaging.md)）。由包管理器安装的副本（`.deb`）和开发构建会提示无法自行更新。
- **自动安装：** 默认关闭。“空闲时”在键盘和鼠标 15 分钟未使用后安装每日检查找到的版本（不报告空闲时间的桌面永远不算空闲）；“每天”在所选的本地时间那一小时内安装。界面运行时每五分钟查看一次；安装失败后等待六小时再试。窗口关闭到托盘时安装的更新，重启后仍在托盘中（`autoInstallDue`、`Prefs.RelaunchHidden`）。

## 首次运行

- 首次运行是一段六步的引导，在一个没有侧边栏的小窗里（`welcomeShell`、`tourView`）；macOS 上左边留一条与图标栏等宽的窗口材质，让红绿灯按钮不压在小窗上。左边是这一步的插图；右边依次是表示各步的圆点、语言与“跳过”、这一步的内容，以及“返回”和“继续”。每一步从前进或后退的方向滑入。
- 各步：**欢迎**（应用做什么、引导讲什么）；**虚拟网卡**（有和没有，可切换对比：只有有虚拟网卡时，本机应用才能访问网络，其他设备在两种情况下都能访问本机）；**运行方式**（三种方式并排成列以供选择，起初为“免授权”：虚拟网卡、本机应用访问网络、网络何时运行、管理员授权）；**开机与登录**（后台服务开机即在线，无需有人登录；另外两种在开启“登录时打开”后，要登录账户才会在线，这一步可直接切换该开关）；**保持在线**（睡眠时任何运行方式都会离线；本系统在哪里保持唤醒，Windows 和 macOS 上带“打开电源设置”）；**准备就绪**（所做的选择；完成时若运行方式需要，会安装特权助手，弹出一次管理员授权）。
- “跳过”会先确认，然后以无需授权的“免授权”方式开始。完成失败（取消授权、安装失败）时，原因显示在按钮旁，直到下一次尝试。
- 插图（`tourart.go`）是绘制的，不是图片：本机从左前上方画出，样子随所运行的系统——Windows Dev Kit、Mac mini、Linux 上的迷你主机——顶面印着系统标志（`computerModel`，标志来自 `assets/logos`）；网络里的设备，数据以移动的虚线表示；运行方式画成电脑的分层，正在运行的网络位于运行它的那一层；开机时间线标出在线的那一段；电脑轮流醒着与睡眠。开启“减少动态效果”时，画面不会自行移动。
- “设置 › 运行方式”中的“重看引导”会以盖住窗口的面板再次显示引导（`tourSheet`），先看到正在使用的运行方式。“关闭”、Esc 或点击外面会回到设置，不改变任何东西；最后一步可切换到刚才查看的运行方式。
- 所有页面都可滚动。

## 节点行

- **名称**（`friendlyName`）：机器风格的主机名（只含 ASCII 字母、数字、`-` 和 `_`）会以空格分词并按常见大小写显示：`macbook-pro` → MacBook Pro，`Intel-NUC8i5BEH` → Intel NUC8i5BEH，`Mac-mini-2024` → Mac mini 2024。用户已写成大写的词保持原样；字母与数字混合的小写词（`nuc8i5beh`）不做改动。其他主机名原样显示。行的提示文字是原始主机名。
- **头像**（`vendorLogo`）：主机名中的某个词指向已知厂商、产品线、操作系统或服务商（`mac`、`iphone`、`nuc`、`linksys`、`windows`、`aws` 等）时，头像显示该厂商的单色标志，颜色与该行一致；否则显示名称的首字母。只匹配完整的词（在分隔符、字母与数字交界、小写与大写交界处切分），因此 `hp` 不会匹配 `php-dev`。硬件厂商优先于操作系统。本机保留圆点。
- **复制：** 右键点击一行（macOS 上为 Ctrl 点击，或 Shift+F10）可选择“复制 IP 地址”“复制 MagicDNS 名称”“复制主机名”；鼠标悬停或焦点在该行时，地址旁会出现复制按钮。复制后会弹出提示，说明复制了什么。
- **MagicDNS 名称**（`magicDNSName`）：小写的 `<hostname>.<zone>`，仅当网络已保存的配置中 `accept_dns = true` 且主机名是单个 DNS 标签时提供。zone 是去掉末尾点的 `tld_dns_zone`，默认为 `et.net`（见 `easytier-upstream.md`）。
- 厂商标志是其所有者的商标，仅用于标识设备厂商；来源列在 `internal/gui/assets/logos/SOURCES.md` 中（见 `packaging.md` 的“厂商标志”）。

## 文案规则

- 文案写给使用应用的人。
- 主界面绝不显示：原因码、revision hash、策略数字、socket 路径、配置 ID。技术细节放进诊断包和日志页折叠的“详细信息”区域。

## 视觉语言

- MyGo 浅色/深色主题加系统强调色；状态、流量和布局数值都是命名 token（`style.go`、`rows.go`）。图标是集中在 `icons.go` 中的 Lucide 线条图标（ISC，`resources/NOTICE`）；Windows 上绘制的窗口按钮仿照 Windows 11 的字形。
- 下载为蓝色，上传为橙色；速率按 1024 进制。
- 延迟：低于 100 ms 绿色，低于 200 ms 橙色，否则红色。路由标签：`p2p`、`relay N`。
- 正文 14，标题 20–24，最小 12。
- 设计线索（颜色、节点行、状态徽标、时间线）参考 [EasyTier-iOS](https://github.com/EasyTier/EasyTier-iOS)；应用图标使用其图形（GPL-3.0-or-later，见 `resources/NOTICE`）。

## 流量图

- 用 MyGo `ui/chart` 绘制：时间轴、面积加单调曲线、悬停读数、取整刻度、图例；1/5/15 分钟窗口。
- 纵轴刻度只在数据超出范围、或长时间低于其三分之一时才调整。
- 缺失的样本是线的断开，绝不是跌到零。
- 只有新样本到达时才更新视图。

## 托盘

- 菜单（Linux AppIndicator 不提供点击事件）：状态行、每个网络一个开关、显示主界面、设置、退出。
- 退出文案随运行方式变化：免授权与随界面方式会断开所有网络；后台服务方式下网络继续运行，另有一项“断开全部并退出”。
- 图标反映已连接/未连接/异常。在深色菜单栏或任务栏上，其灰色和蓝色更浅，并随其外观变化，即使应用自身的主题不同。关闭窗口会隐藏到托盘，第一次会提示；没有托盘时关闭即退出。
- macOS：关闭到托盘时也会隐藏程序坞图标（设置 → 通用，默认开启；登录时隐藏启动也一样）。最小化时保留图标；显示窗口时图标恢复。
- macOS：登录项启动时没有命令行参数，系统只在应用完成启动时告知它是登录时打开的，因此界面在就绪后才询问，而不是之前。

## 语言

通过 MyGo 的 ARB 目录提供英文、简体中文、繁体中文和日文（`go tool mygo i18n check`）。默认跟随系统语言，可以手动切换。
