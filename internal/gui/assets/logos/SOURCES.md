# Vendor logo sources

Monochrome vendor marks that the peer list draws inside a peer's avatar when its hostname names a
known maker, product line or operating system (see `internal/gui/vendorlogo.go`). How to add or
update a logo is described in `doc/en-us/packaging.md`, "Vendor logos".

- **41** files are [Simple Icons](https://simpleicons.org/) SVGs (CC0 1.0), byte-identical in path
  data with the `simple-icons` package.
- **6** files are public-domain logo SVGs from Wikimedia Commons (text or simple-geometry logos not
  eligible for copyright).
- **16** files have no recorded source; no identical file exists in Simple Icons releases 5 through
  the current one. They are listed as such so they can be replaced or removed.

**Trademarks.** Every file here is a trademark of the brand named in its row. The marks are used
only to identify the maker of a device, as nominative use; their use implies no affiliation with
or endorsement by the owner, and a mark will be removed if its owner asks. Copyright status (the
"License" column) is separate from trademark rights, which CC0 and public domain do not waive.
These files are not part of EasyTier MyGo's GPL-3.0 source.
